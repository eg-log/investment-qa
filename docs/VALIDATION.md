## 2. 재현 검사 도구

`scripts/check_package.py`는 Python 구문, 노트북 및 추론 정의의 무결성, README 링크, 모델 파일, 의존성 버전을 검사한다. `--code-only`는 정적 검사 결과만 종료 상태에 반영하며 실제 서비스 실행 성공을 뜻하지 않는다.

`scripts/smoke_test.py`는 학습 파이프라인의 fit 호출을 차단한 상태로 저장 가중치를 로드하고 다섯 가지 시연 질문, 후속 맥락, 잘못된 입력, Gradio 화면 생성을 확인한다. 결과 파일은 기존 시험 평가와 별도로 생성된다.

## 3. 미검증 범위

- 현재 배포 환경에서 동일한 의존성을 설치한 뒤 수행하는 실제 서버 실행
- 상시 공개 URL의 로그아웃 브라우저 접속과 실제 예측
- 공개 서비스의 응답 시간·재시작·동시 접속 안정성
- 독립 수동 검수된 원칙·실사용 질문과 새로운 기관·시점의 일반화

Colab 실행 기록, 저장 파일 검사, 상시 공개 배포는 각각 다른 검증 범위이다. 저장 파일이 존재하거나 정적 검사를 통과했다는 사실만으로 외부 배포 완료를 판단하지 않는다.
